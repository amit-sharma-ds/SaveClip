# SaveClip [Video Downloader Extension Without Watermark

SaveClip is a browser extension that lets you download Meta AI generated videos easily without any watermark.

## Features
- One-click download of Meta AI videos.
- Removes watermarks automatically.
- Works on Meta AI web/app interfaces.
- Supports high-quality exports (up to 4K where available).

## Installation
1. Download the extension files.
2. Open your browser's extension manager (e.g., chrome://extensions/).
3. Enable "Developer mode".
4. Load the unpacked extension folder.

## Usage
1. Generate a video using Meta AI.
2. Click the SaveClip icon in your browser toolbar.
3. Select download quality.
4. Video saves to your Downloads folder watermark-free.

## Compatibility
- Chrome, Firefox, Edge.
- Meta AI on web, WhatsApp, Instagram, Facebook.
